The design

The design says what each column of the count table is: which sample, its role, its replicate and time point. MaveScape drafts it from the column names; you check it in the Experiment view.

Drafting the design

Once a table is open, the workflow strip offers Draft the design. MaveScape reads the column names (input, pre, lib; output, post, sel; rep1; t0, gen3; bin1; tile2), finds shared samples by comparing the columns' values, and sets aside every column it does not use, with the reason. The number of time points tells conditions apart: two assays in one table become two conditions.

The Experiment view

The design is two tables. Columns → samples: each column is a sample of its own, a technical replicate of another (summed), a copy of a shared sample's column, or not used, with why. Replicates × slots: each replicate's input and output, its time points (edited in the column heads) or its bins, with its condition and tile. Beside them: the kind of experiment, the controls, the time unit, and the target's name, offset, coding start and identifiers.

Every change is checked as you make it. The design is described in plain words, and each error and warning is listed: a column that is neither a sample's nor set aside is an error, so nothing is dropped silently.

Sample sheets

A sample sheet is a table with one row per sequenced sample: its column, role, replicate and, as needed, technical replicate, condition, time, bin, value and tile. Columns are recognized under many names, and DiMSum's experiment design file reads as a sample sheet. A sample shared by several replicates lists them (1;2;3).

column,role,replicate,technical_replicate,condition,time,bin,value,tile
input_rep1,input,1,1,,,,,
output_rep1,output,1,1,,,,,

Design files and history

A design is saved and opened as *.design.json, described by a JSON schema in the repository. Every material change to the workspace (an import, a target, the design) goes into its history, each entry chained to the one before by its hash, so that an entry edited afterward is caught. The drawer (⌘J) shows it.
