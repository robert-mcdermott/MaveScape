--- title: Install layout: page heading: Install MaveScape description: Install MaveScape on macOS, Linux or Windows with one command. One self-contained program, checked against its SHA-256 checksum, with no administrator rights needed. lede: MaveScape is one executable. The browser application and the example experiments are inside it, so nothing else needs to be installed. One command downloads the release for your computer, checks it and installs it. --- 
$ curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/robert-mcdermott/mavescape/main/install.sh | sh

Installs the latest release as ~/.local/bin/mavescape. No sudo, and your PATH is left as it is; if ~/.local/bin is not on it, the installer prints the full path to run.

PS> irm https://raw.githubusercontent.com/robert-mcdermott/mavescape/main/install.ps1 | iex

Run in PowerShell. Installs to %LocalAppData%\Programs\MaveScape and adds it to your user PATH. No administrator rights and no change to the execution policy needed.

Start it

$ mavescape

MaveScape starts a local server on http://127.0.0.1:8820 (or the next free port) and opens its window. If Chrome, Edge, Brave or Chromium is installed, the window is a desktop app window with its own profile; otherwise your default browser is used. Closing the window stops the program. On Windows, open a new terminal after installing so that it sees the updated PATH.

Files and folders named on the command line open directly, and running mavescape <files> again while it is open hands them to the open window:

$ mavescape counts.csv target.fasta

Then continue with Getting started.

The window is a page in a current browser; MaveScape is tested in Chrome and the browsers built on Chromium. Each release has SHA256SUMS, the checksum of every file; the installers require exactly one matching checksum and run the downloaded program's --version before moving it into place, so a failed download never replaces a working copy.

Options

To install a particular release, or somewhere else:

$ curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/robert-mcdermott/mavescape/main/install.sh | MAVESCAPE_VERSION=v{{version}} MAVESCAPE_INSTALL_DIR="$HOME/bin" sh

In PowerShell, set $env:MAVESCAPE_VERSION and $env:MAVESCAPE_INSTALL_DIR before the same command. To read an installer before running it, download it first; INSTALLING.md describes every option, and how to install by hand.

Command-line options

OptionMeaning
mavescape [files or folders]Start and open the files: count and score tables, sequences, designs, workspace archives
--port NPreferred port (default 8820; the next 19 are tried)
--window app|browser|noneA desktop window, the default browser, or none
--data-dir DIRWhere the workspace library is kept
--no-libraryKeep workspaces in the browser's storage instead
--keep-runningKeep serving after the window is closed
--remote-controlLet programs on this computer drive the window (Remote control)
--versionPrint the version
mavescape run …Score a table with its design without a window (Headless runs; mavescape run -h)
mavescape validate …Check tables and a design as scoring would (Checking before scoring)

Uninstall

Delete the program (~/.local/bin/mavescape, or %LocalAppData%\Programs\MaveScape on Windows). Your workspaces are in the library folder the status bar names, ~/Library/Application Support/MaveScape on macOS; keep or delete it as you like.
